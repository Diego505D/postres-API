### Archivo app.js 
- src \app.js backend
Registra las rutas de los postres e inicia el servidor en el puerto 3000.
- public \index.html frontend
Se encarga de la interfaz de usuario como los botones de eliminar registrar venta y seleccionar que tipo de postre, tambien tiene la funcion de mostrar los postres en tarjetas.

Al separar las responsabilidades, se encontró que el proyecto queda más organizado y es más fácil entender qué función cumple cada parte. También facilita encontrar y corregir errores sin afectar todo el código. Después de realizar esta actividad, cambiaría la forma en que se organizaron algunos proyectos anteriores, separando mejor las funciones y responsabilidades para que el código sea más limpio y fácil de mantener.
